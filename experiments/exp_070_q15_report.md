## Контекст (для новых итераций — прочитай это первым)

**UAF** — система с уравнением:
`dA_i/dτ = α_s·C_ij·A_j·(1−A_i) + α_l·Π_i·PE_i·(1−A_i) + f·(1−A_i) − δ·(1−0.3A_i)`

**Ключевые числа:**
- A*_uns(f) = A*_uns(0) − 28·f  (EXP 066, LST)
- slope_net = k₀·slope_1D/<k>  (EXP 068)
- k₀ пиковая при δ/δ*=0.75, обвал к δ*  (EXP 069)
- **Q15**: что лучше — добавить связей или поднять floor?

### 070-B: Закон обратного масштабирования (ГЛАВНЫЙ РЕЗУЛЬТАТ)

**A*_uns(f=0, mk) × mk = K = const**

| mk | A*(f=0) | mk × A* | K/mk |
|----|---------|---------|------|
| 2  | 0.09944 | **0.19889** | 0.09945 |
| 4  | 0.04976 | **0.19904** | 0.04973 |
| 8  | 0.02493 | **0.19942** | 0.02486 |
| 20 | 0.00999 | **0.19975** | 0.00995 |
| 30 | 0.00666 | **0.19983** | 0.00663 |

**K = 0.1993 ± 0.0003 (CV = 0.002) — точный закон.**

**Аналитический вывод:**

При малых A (водораздел ≈ 0), f=0:
```
(α_s·mk + α_l)·A ≈ δ
→ A*_uns ≈ δ / (α_s·mk + α_l)
→ K = mk·A* ≈ δ/α_s = 0.012/0.06 = 0.200
```

Измеренное K = 0.1993 — поправка от α_l члена составляет 0.35%.

**Следствие**: каждое добавленное ребро даёт **пропорциональный** выигрыш:
```
ΔA*_uns / A*_uns = −1/mk  (при увеличении mk на 1)
```
Убывающая абсолютная отдача, **постоянная относительная**.

### 070-C: Маргинальный анализ

| mk | A*(f=0) | |dA*/dmk| | |dA*/df| | ratio |
|----|---------|----------|---------|-------|
| 2  | 0.083   | 0.041    | 8.33    | 0.0050 |
| 4  | 0.041   | 0.010    | 4.15    | 0.0025 |
| 8  | 0.021   | 0.003    | 2.08    | 0.0013 |

Floor **всегда** в ~400 раз более эффективен на каждую единицу стоимости локально.

НО: базовый уровень определяется связностью: A*_uns(0) = K/mk.

**Перекрёстная точка**: mk_eq = √(K/|slope_1D|) = √(0.1993/28) = **0.084**
— это виртуальная точка, реальные сети всегда выше. Поэтому floor всегда
маргинально эффективнее, но связность задаёт порядок величины.

### 070-D: Объединённая формула и оптимальное распределение

При малом f: `A*_uns(f, mk) ≈ (K − 16.6·f) / mk`

**Оптимальное распределение бюджета B = mk + f:**

Равенство маргинальных отдач:
```
16.6/mk = (K − 16.6·f)/mk²
→ mk* = (K − 16.6·f) / 16.6
```

При B=5: mk*=5.0, f*=0.001, A*_uns=0.037 (лучше чем только mk=5: 0.040 или только f=3.5: 0.019+коррекция).

**Численно подтверждено**: оптимальный сплит превосходит крайние стратегии.

## Принцип Q15

> **Связность доминирует абсолютно; floor — маргинально.**

- Для новой системы: сначала максимизировать связность (1/mk закон)
- Для хорошо связанной системы у δ*: добавить floor (маргинально эффективнее)
- Комбинированная стратегия: mk* = (K − 16.6·f) / 16.6

## Q16 (следующий)

**K = δ/α_s — топологически инвариантна?**

Вывод получен для HMF (среднее поле на BA). Для других топологий:
- Erdős-Rényi: <k²> ≈ <k>+<k>² → другой лапласиан
- Регулярная решётка: все степени одинаковы
- Звезда: один хаб, все листья

**Гипотеза**: K = δ/α_s не зависит от топологии (только от α_s и δ).

Это следует из аналитики: при малых A, f=0:
```
α_s·mk·A = δ  →  K = mk·A = δ/α_s
```
В этом пределе только α_s и δ входят в K — топология через mk.

Если верно: **K — динамический инвариант UAF**, независимый от сетевой структуры. Тогда вся серия Q11–Q15 сводится к:

```
A*_uns ∝ δ / (α_s · mk · (1 + α_l/α_s·mk))
```

Проверяемо за одно сравнение ER vs BA при одинаковом <k>.
