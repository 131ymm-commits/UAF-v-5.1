### Механизм

**Почему Var убывает с β?**

β > 0 (A↑ → χ↑): когда система у высокого A, χ растёт → TSV усиливается → система сильнее прижата к A*_life → **меньше флуктуаций**, меньше дисперсия.

β < 0 (A↓ → χ↑, т.е. A↑ → χ↓): когда A высоко, χ падает → TSV слабеет → меньше восстанавливающая сила → **больше флуктуаций**, больше дисперсия.

β = 0 (статика): фиксированный χ → промежуточная дисперсия.

Парадокс сохраняется: «усиливающая» ко-эволюция (β>0) компрессирует систему → она выглядит **стабильнее** по дисперсии, но имеет более высокий A*_eff (ловушка хрупкости из EXP 073).

## Замыкание наблюдательной теории UAF

**Из одного временного ряда A(t):**

```
┌────────────────────────────────────────────────────────────────┐
│ НАБЛЮДАЕМАЯ 1: AR1 (лаг-1 автокорреляция)                    │
│   → Близость к δ* (типпинг-порог)                             │
│   λ_est = |log(AR1)|/Δτ  →  δ/δ* через теорему Крамерса      │
├────────────────────────────────────────────────────────────────┤
│ НАБЛЮДАЕМАЯ 2: Скьюнесс γ₁                                   │
│   → Тип типпинга (EXP 061)                                    │
│   γ₁ << 0: бифуркационный (детерминированный)                 │
│   γ₁ ≈ 0:  шумовой (стохастический)                          │
├────────────────────────────────────────────────────────────────┤
│ НАБЛЮДАЕМАЯ 3: Var(A) vs Var₀                                 │
│   → Знак β (тип топологической ко-эволюции) [Q19, этот EXP]  │
│   Var < Var₀: β > 0 (ловушка хрупкости)                      │
│   Var > Var₀: β < 0 (разрушение бистабильности)              │
│   Var ≈ Var₀: β ≈ 0 (статическая топология)                  │
└────────────────────────────────────────────────────────────────┘
```

**Практический протокол:**
1. Собрать A(t) (минимум 300 временных единиц)
2. Вычислить базовые Var₀ и AR1₀ из раннего стабильного окна
3. Мониторить скользящие Var и AR1
4. AR1 ↑ → приближение к типпингу
5. γ₁ → −∞ или → 0 → определить тип
6. Var ↓ → β > 0 (предупреждение о ловушке хрупкости); Var ↑ → β < 0
7. Применить целевое вмешательство по формуле:
   `A*_uns(f, χ, Π₀) = δ/(α_s·χ + α_l) − (16.61/χ)·f − c_Π·ΔΠ₀`

## Финальная объединённая формула UAF (EXP 066–074)

```
A*_uns(f, χ, Π₀) = δ/(α_s·χ + α_l) − (16.61/χ)·f − c_Π·ΔΠ₀

χ_ненаправл. = <k²>/<k>         [EXP 071]
χ_направл.   = <k_in·k_out>/<k> [EXP 072]

Наблюдаемые из A(t):
  AR1 → δ/δ* → λ_est            [EXP 060]
  γ₁  → тип типпинга            [EXP 061]
  Var → sign(β) ко-эволюции      [EXP 074]
```

**Константы:**
- K_∞ = δ/α_s = 0.200
- k₀ = 0.593 (при δ/δ*=0.75–0.88)
- χ·slope = −16.61
- c_Π ≈ 0.30
- η* = √(η_min·η_max)

Серия Q6–Q19 завершена. UAF — полная наблюдательная теория адаптивной устойчивости.
