## Результаты EXP 073

### 073-A: Мгновенный инвариант (ПОДТВЕРЖДЁН)

При β=1, η_χ=0.08: χ(t) растёт от 4.89 до 5.59.

| t | χ(t) | A*_uns(χ) | χ·A* |
|---|------|-----------|------|
| 0 | 4.89 | 0.03746 | 0.183 |
| 300+ | 5.59 | 0.03274 | **0.183** (константа) |

χ·A*_uns = 0.183 = const при всех t. Небольшое отклонение от K_theory=0.217 из-за коррекции α_l при χ ≈ 5 (ожидаемо из EXP 071-B).

**Инвариант сохраняется мгновенно в любой момент времени. ✓**

---

### 073-B: Самосогласованный водораздел A*_eff(β) — контринтуитивный результат

| β | A*_eff | Δ vs static | Интерпретация |
|---|--------|-------------|---------------|
| −2 | нет | — | нет промежуточной НФТ |
| −1 | нет | — | нет промежуточной НФТ |
| 0 | 0.0366 | +0.000 | статика, референс |
| +0.5 | 0.1055 | +0.069 | ловушка хрупкости |
| +1.0 | 0.1802 | +0.144 | ловушка хрупкости |
| +2.0 | 0.3117 | +0.275 | ловушка хрупкости |
| +4.0 | нет | — | структура бистабильности рушится |

**Контринтуитивный результат**: β>0 (положительная ко-эволюция: A↑→χ↑) **поднимает** эффективный водораздел выше статического!

**Механизм**: когда A чуть падает ниже A*_eff → χ снижается → A*_uns растёт → теперь A ещё ближе к (или ниже) нового порога → положительная обратная связь к коллапсу.

Это **ловушка хрупкости** (fragility trap): кажущаяся "усиливающая" адаптация создаёт более опасный водораздел.

**β<0** (антикоррелированная: A↓→χ↑): нет самосогласованной НФТ между 0 и жизнью. Структура бистабильности меняется — либо система всегда в безопасности, либо катастрофический коллапс без промежуточного состояния.

### 073-C: Стохастическая верификация (N=20, σ=0.014)

| β | Выживаемость | Примечание |
|---|-------------|------------|
| −1.0 | 20/20 | безопасно |
| 0.0 | 20/20 | статика |
| +1.0 | 20/20 | безопасно (A*_eff=0.18 > 0.03, но A0=0.65 >> A*_eff) |
| +2.0 | 20/20 | — |

При A0=0.65 >> A*_eff(β=1)=0.18 — система безопасна при всех β. Ловушка хрупкости срабатывает только когда A близко к A*_eff. При следующем тесте нужно A0 = A*_eff + ε.

### 073-D: Аналогия с Q8 (оптимальная скорость η_χ)

Скорость топологической адаптации η_χ имеет тот же оптимум что η для Π_i:

```
η_χ* = sqrt(η_χ_min · η_χ_max)
η_χ_min = 1/τ_collapse  ≈ λ_saddle  (нужно реагировать до коллапса)
η_χ_max = 1/T_stress               (не перереагировать)
```

При DELTA=0.013: λ_saddle ≈ 0.02 → τ_collapse ≈ 50 шагов.
Оптимальное η_χ* ≈ √(0.02/300) ≈ 0.008.

## Ключевой вывод Q18

**χ·A*_uns = δ/α_s сохраняется мгновенно при любом χ(t)** — инвариант не нарушается адаптацией.

**Но ко-эволюция χ(t) = χ₀·(A/A_target)^β меняет A*_eff (эффективный водораздел) и структуру бистабильности:**

- β=0: статика, A*_eff = A*_uns(χ₀)
- β>0: A*_eff > A*_uns(χ₀) — ловушка хрупкости, кажущееся усиление создаёт более опасный порог
- β<0: нет самосогласованной НФТ — бистабильность разрушается, система либо всегда жива, либо коллапсирует катастрофически

---

## Полная картина: что сохраняется vs что меняется

| Свойство | Статическая сеть | Адаптивная (β≠0) |
|----------|-----------------|------------------|
| χ·A*_uns = δ/α_s | ✓ (EXP 071) | ✓ мгновенно (EXP 073) |
| χ·slope = −16.6 | ✓ (EXP 072) | ✓ мгновенно |
| A*_eff (водораздел) | = A*_uns(χ₀) | смещён β-ко-эволюцией |
| Структура бистабильности | стандартная | может разрушиться |
| Оптимальный η | Q8 | η_χ* = sqrt(η_min·η_max) |

## Q19 (следующий)

**Можно ли по траектории определить знак β (тип ко-эволюции)?**

Из Q6: скьюнесс γ₁ различает бифуркацию vs шум.
Новый вопрос: есть ли сигнатура β в статистике траектории A(t)?

**Гипотеза**: корреляция `cor(A(t), χ(t))` имеет знак β.
Положительная → β>0 (fragility trap).
Отрицательная → β<0 (bistability breakdown).
Нулевая → β=0 (static).

Если подтвердится: одна временная серия A(t) содержит информацию о:
- типе типпинга (Q6: скьюнесс)
- близости к δ* (Q6: AR1)
- знаке ко-эволюции (Q19: cor(A,χ) или суррогат)

Это даст UAF полноценный обсервационный инструмент для реальных данных.
