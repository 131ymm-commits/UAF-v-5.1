# Отчёт: Инвариант для направленных сетей
# ========================================

## Контекст (читай в начале каждой итерации)

**Серия EXP 060–072 одной строкой:**
CSD→тип→R-тип→η*→η-авто→Π-капитал→LST(1D)→LST(сеть)→C=k₀χ/<k>→
k₀(δ/δ*)→связность-vs-floor→χ·A*=δ/α_s(ненаправл.)→**χ_dir·A*=δ/α_s(направл.)**

**Ключевой инвариант (EXP 071):** `χ·A*_uns = δ/α_s = 0.200`
где χ = <k²>/<k> для ненаправленных сетей.

**Q17:** то же для направленных (χ_dir = <k_in·k_out>/<k>)?

### 072-D: Формулы χ_dir для распространённых моделей

| Модель | χ_dir |
|--------|-------|
| Ненаправленная | <k²>/<k> |
| Ненаправл. ER | 1 + <k> |
| Направленная (k_in ⊥ k_out) | <k> |
| Направленная ER (Пуассон) | 1 + <k> ← совпадает с ненаправл.! |
| Ассортативная (k_out = k_in) | <k²>/<k> |
| Степ.-зак. (equal, γ) | > <k> |
| Отриц. смешивание | < <k> |

Интересный факт: **ER ненаправленная и ER направленная имеют одинаковый χ = 1+<k>** и, следовательно, одинаковое A*_uns. Направленность не имеет значения при некоррелированном распределении степеней типа Пуассон.

## Финальная объединённая формула UAF (EXP 066–072)

```
A*_uns(f, χ, Π₀) = δ/(α_s·χ + α_l) − (16.61/χ)·f − c_Π·ΔΠ₀

χ_ненаправл. = <k²>/<k>
χ_направл.   = <k_in·k_out>/<k>

K_∞ = δ/α_s = 0.200  (топологически-свободная константа)
```

Единственный сетевой параметр — χ. Всё остальное — динамика UAF.

## Q18 (следующий)

**Инвариант в адаптивных (динамических) сетях?**

Пока: фиксированная топология. В адаптивных сетях рёбра
формируются/рвутся в зависимости от состояния агентов A_i.

**Два сценария:**

Положительная обратная связь (fragility cascade):
```
A_i ↓ → рёбра рвутся → χ ↓ → A*_uns ↑ → A_i ещё ↓ → ...
```

Отрицательная (resilience amplification):
```
A_i ↑ → новые рёбра → χ ↑ → A*_uns ↓ → A_i держится → ...
```

**Предсказание из формулы**: A*_uns(χ(t)) = δ/(α_s·χ(t) + α_l).
Если χ(t) падает быстрее чем A_i → положительная обратная связь → катастрофический коллапс.
Если χ(t) растёт с A_i → буферирование, более мягкий переход.

Критическая скорость адаптации: η_χ = dχ/dA. Если η_χ > α_s/(α_l) — сеть адаптируется достаточно быстро для защиты. Это прямой аналог Q8 (оптимальная скорость обучения η), но для топологии.
