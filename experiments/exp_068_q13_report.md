### Физическая интерпретация

**Почему именно <k>?**

Floor f добавляет f·(1−A_i) к каждому агенту. Это одинаково для всех агентов независимо от степени. Но эффект на водораздел определяется тем, насколько агент «изолирован» от соседей:

- При высоком <k>: агент получает много TSV от соседей → floor является малой добавкой к уже сильному восстанавливающему усилию → эффект floor на A*_uns слабее
- При низком <k>: floor — главный источник восстановления → эффект сильнее

Математически: slope = d(A*_uns)/df = −1/(|λ_saddle| + α_s·<k>·correction). При больших <k> знаменатель растёт → slope → 0.

**Почему λ_max не важен?**

λ_max определяет **порог распространения** (выживает ли система вообще), но не **чувствительность к floor**. Это разные свойства: порог распространения vs. линейная чувствительность водораздела к параметрам.

---

### Двойственность: floor и стресс-обучение через <k>

**Эффект floor:**
```
slope_net = −16.611 / <k>
```
Чем выше <k>, тем СЛАБЕЕ floor на единицу.

**Стресс-обучение (накопление Π за один эпизод):**
```
ΔΠ_per_stress ∝ <k> · A*_life · α_l
```
Чем выше <k>, тем БЫСТРЕЕ накапливается точность.

**Совместный эффект — <k> СОКРАЩАЕТСЯ:**
```
ΔA*_uns_total = (floor term) + (learning term)
              = (k₀·slope_1D/<k>)·f + n·c_π·c_A
```

Первый член зависит от <k>, второй — нет. При совместном использовании:
- Хорошо связанные сети: быстрее учатся, но floor менее эффективен
- Слабо связанные сети: медленнее учатся, но floor более эффективен

**Вывод**: топология сети самобалансирует накопление устойчивости. При правильном подборе floor + стресса — результат одинаков независимо от <k>.

**Практическое правило:**
```
f* = (A*_uns(0) − t) · <k> / 16.611
```
Целевой floor для достижения порога t: **линейно растёт с <k>**.

## Q14 (следующий)

**k₀ ≈ 0.593 — универсальная константа?**

Измерено при δ = 0.012 ≈ 0.82·δ*. Вблизи δ*:
система более чувствительна → k₀ может меняться.

**Предсказание:**
```
k₀(δ) = k₀₀ · (1 − δ/δ*)^β
```

- Если β = 0: k₀ универсальна
- Если β > 0: k₀ → ∞ вблизи δ* (критическое масштабирование)
- Аналог: показатель критической сингулярности в теории фазовых переходов

**Физический смысл**: вблизи типпинга система бесконечно чувствительна к floor (λ_saddle → 0). Если k₀ не зависит от δ/δ*, то всё критическое усиление захвачено slope_1D. Если зависит — есть отдельный сетевой критический экспонент.

Проверяется за один sweep δ при фиксированном <k>.
